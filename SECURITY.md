# Security

Tab Amnesty keeps a record of people's browsing, so a weakness in it matters even though nothing
ever leaves the computer.

## Reporting a vulnerability

Please report privately through GitHub: the repository's **Security** tab → **Report a
vulnerability**. Do not open a public issue, and do not include anyone's real page titles,
addresses or exported files — describe the shape of the data instead.

## In scope

- Anything that sends data off the computer, or lets another site or extension read what Tab
  Amnesty keeps.
- A web page (or a frame in it) changing what is recorded, closed, opened or forgotten.
- A file brought in through **Keep a copy** doing more than adding cards, or a saved copy running
  script when opened.
- Anything kept about a site on the never-remember list, about incognito windows, or after
  **Forget this**.

## What to expect

This is a small open-source project maintained in spare time: reports are read and answered on a
best-effort basis, fixes ship in the next release, and reporters are credited unless they prefer
not to be.
