# UX Profile

Generated by `setup-ui-ux-skills` (2026-11-10). All UI/UX skills in this project read this file
before changing layout, copy, or interaction. `CLAUDE.md` §6 (the human design rules) outranks
anything here; this file is how those rules look.

## Aesthetic reference

- **Standard:** Notion
- **Notes:** Already the look of the sweep page (`src/ui/sweep/index.html` `:root` tokens), and
  the right one for people who mostly have ADHD: calm, warm, nothing shouting. Warm paper
  `--bg #fbfaf7` (dark `#1b1a18`), ink `--fg #23211d`, soft grey `--muted #736e64` (4.86:1 on the paper), hairline
  `--line #e8e4db`, white cards `--card`, one muted blue accent `--accent #4a6fa5` (dark
  `#8fb0e0`), field borders `--edge #8f897e` (dark `#76716a`, 3:1 for inputs), each with a dark-mode value under `prefers-color-scheme`. Groups are cards with a
  5 px left rule in their Chrome tab-group colour (the fixed enum, §5.6) — the only colour beyond
  the accent. `system-ui` type at 15 px / 1.5; page title 20 px / 600; group names 16 px / 600.
  Separation by hairline borders and background shift; the only shadow is the toast. Plain DOM,
  no UI framework. The saved copy (`src/archive/copy.ts`) reuses these tokens. Paper and block
  discipline only: no callout pastels, stickers or illustration.

## Banned anti-aesthetics

- Gratuitous glassmorphism (`backdrop-filter` without a hard edge)
- Neon glowing borders and multi-stop rainbow CTAs
- Floating pastel pill badges for ordinary metadata
- Decorative blob / mesh gradients behind content
- Nested scroll regions (page + card + list all scrolling)
- Cartoon people waving, high-fiving or celebrating; huge centred illustrations with no action
- Icons inside inputs unless functional (search, clear)
- Soft drop-shadows as the only separator
- A disabled primary button as the only feedback on an incomplete form
- **Project bans (`CLAUDE.md` §6):** any number about how many tabs someone has, a size in GB, a
  red badge, a streak or a "you haven't…" line; the words delete, clean up, declutter, tidy and
  messy anywhere in the UI; anything that characterises someone's browsing; an empty "name this"
  field; per-tab checklists; more than five decisions visible at once; timers, auto-close or
  "smart" anything that closes tabs; alarm colours for having many tabs open.

## Accessibility target

- **Level:** WCAG 2.1 AA, plus W3C COGA (cognitive accessibility) as `CLAUDE.md` requires
- **Contrast:** at least 4.5:1 for normal text (including the 12–13 px muted metadata), 3:1 for
  large text, borders that carry meaning and focus indicators — in light and in dark.
- **Touch / focus:** 44 × 44 px targets for primary actions (Archive & close, Bring back, Open
  all, Save a copy); the quiet text buttons (Forget this, Open) keep at least 24 × 24 px with
  space around them; a visible 2 px focus outline in `--accent` on every control; nothing reachable
  only by pointer; no single-key shortcuts without an off switch (WCAG 2.1.4).

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain, literal and kind — COGA language: say what will happen, in everyday words, no
  jargon, no shame, no exclamation marks, no numbers about someone's tabs. The established
  vocabulary: "put away", "bring back", "open all", "forget this", "never remember", "keep a
  copy" — keep using these words for these things. Buttons are a verb and an object. Group names
  are proposed, never asked for (§6.7); when is said as an event ("this afternoon", "Wednesday
  afternoon"), dates only as small secondary metadata (§6.5). Reassure about safety where it
  matters ("Everything is kept on this computer").

## Icon library

- **Library:** Project SVG
- **Package / path:** `public/icons/` (today only the extension's own icon, `icon.svg`, rendered
  by `npm run icons`)
- **Notes:** The UI's controls are text-labelled on purpose (COGA: words, not symbols). If an
  icon is ever needed, draw it inline in the same flat style as `icon.svg`, always beside its text
  label. No icon package, no mixing sets, no emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog. Here that means **Forget this**
   (permanent) and adding a site to never remember (forgets what was kept about it). **Archive &
   close is not destructive** — everything is kept and Bring back works for a day — so it stays
   one click, per group (§6.9).
